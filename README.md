# Fenster-Mapper

Einfache Projection-Mapping-App im Browser (eine einzige HTML-Datei, ohne Installation).

- Video oder Bild auf ein Fenster mappen, Rahmen über vier Eckpunkte anpassen
- Masken zum Abdecken von Fensterrahmen und Sprossen
- Effekte (Scan, Balken, Wellen, Radar, Ringe, Aurora, Sternbild, Pixel-Regen)
- Testraster zum Einmessen, Vollbild-Output für den Beamer (Taste F)

Öffnen: `index.html` im Browser (Chrome oder Edge empfohlen).
