# Fenster-Mapper

Einfache Projection-Mapping-App im Browser (eine einzige HTML-Datei, ohne Installation).

- Video oder Bild auf ein Fenster mappen, Rahmen über vier Eckpunkte anpassen
- Masken zum Abdecken von Fensterrahmen und Sprossen
- Effekte (Scan, Balken, Wellen, Radar, Ringe, Aurora, Sternbild, Pixel-Regen, Spinnennetz, Fledermäuse, Nebel)
- Text mit verschiedenen Schriften, Glühen und Animation (Flackern, Pulsieren)
- Halloween-Vorlagen auf Knopfdruck
- Projekte lokal speichern (inklusive Video und Bild, im Browser) sowie als Datei sichern und öffnen
- Kantengriffe für Breite und Höhe, Zurück/Vor (Strg+Z / Strg+Y), aufklappbares Menü
- Testraster zum Einmessen, Vollbild-Output für den Beamer (Taste F)

Öffnen: `index.html` im Browser (Chrome oder Edge empfohlen).
